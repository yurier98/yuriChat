# GoyRENT

GoYRENT es una plataforma de software como servicio (SaaS) diseñada para gestionar alquileres y préstamos de productos y servicios. A través de una interfaz intuitiva y herramientas avanzadas, GoYRENT permite a las empresas optimizar la conexión entre proveedores y clientes, mejorando la eficiencia y eficacia en el proceso de alquiler.

**Problema que soluciona:** En el entorno empresarial actual, muchas organizaciones enfrentan desafíos significativos relacionados con la falta de visibilidad de sus productos, la desorganización en la gestión de pedidos y la dificultad para mantener un control preciso del inventario. Estos problemas no solo afectan la productividad, sino que también generan frustración entre los clientes y pueden resultar en pérdidas económicas.

**Resumen de la propuesta de valor:** GoYRENT ofrece una solución integral que mejora la gestión de alquileres al integrar herramientas de visibilidad de productos, reservas en línea, gestión de pedidos y seguimiento de inventarios en una sola plataforma. Nuestro producto permite a las empresas aumentar la eficiencia operativa, mejorar la satisfacción del cliente y tomar decisiones informadas basadas en datos. Con una escalabilidad fácil y un enfoque centrado en el usuario, GoYRENT se posiciona como una opción atractiva para empresas de todos los tamaños.

## ⚒️ Tech Stack

**Backend Framework** → [Django](https://www.djangoproject.com/)  
Framework de Python de alto nivel para el desarrollo rápido y limpio del backend.

**API Framework** → [Django REST Framework](https://www.django-rest-framework.org/)  
Toolkit flexible para construir APIs Web RESTful.

**Frontend Framework** → [Nuxt.js](https://nuxt.com/)  
Framework full-stack sobre Vue.js para construir aplicaciones universales y SPA.

**Containerization** → [Docker](https://www.docker.com/)  
Plataforma para empaquetar, distribuir y ejecutar aplicaciones en contenedores.

**Architecture** → Microservicios  
Arquitectura que estructura una aplicación como una colección de servicios débilmente acoplados.

**Database** → [PostgreSQL](https://www.postgresql.org/)  
Sistema de base de datos objeto-relacional de código abierto.

**Caching** → [Redis](https://redis.io/)  
Almacén de estructura de datos en memoria, usado como base de datos, caché y agente de mensajes.

**Task Queue** → [Celery](https://docs.celeryq.dev/)  
Sistema de cola de tareas distribuida basada en paso de mensajes.

JSON Web Tokens para autenticación stateless y segura.
